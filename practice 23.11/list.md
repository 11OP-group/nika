# Справочная таблица методов списков и строк

| Метод / Оператор | Что делает | Пример |
| :--- | :--- | :--- |
| `append(x)` | Добавить элемент `x` в конец списка | `[1, 2].append(3)` → `[1, 2, 3]` |
| `extend(iterable)` | Расширить список элементами другого итерируемого объекта | `[1, 2].extend([3, 4])` → `[1, 2, 3, 4]` |
| `insert(i, x)` | Вставить элемент `x` на позицию с индексом `i` | `[1, 3].insert(1, 2)` → `[1, 2, 3]` |
| `del list[i]` | Удалить элемент по индексу `i` (оператор) | `a = [10, 20]; del a[0]` → `[20]` |
| `remove(x)` | Удалить первое вхождение элемента `x` | `[1, 2, 2].remove(2)` → `[1, 2]` |
| `pop([i])` | Удалить и вернуть элемент (по умолчанию последний) | `[10, 20].pop()` → вернет `20`, список `[10]` |
| `clear()` | Удалить все элементы из списка | `[1, 2].clear()` → `[]` |
| `index(x)` | Вернуть индекс первого вхождения элемента `x` | `['a', 'b'].index('b')` → `1` |
| `count(x)` | Посчитать количество вхождений элемента `x` | `[1, 1, 2].count(1)` → `2` |
| `copy()` | Создать поверхностную копию списка | `a = [1]; b = a.copy()` |
| `reverse()` | Развернуть список в обратном порядке (на месте) | `[1, 2, 3].reverse()` → `[3, 2, 1]` |
| `sort()` | Отсортировать список по возрастанию (на месте) | `[3, 1, 2].sort()` → `[1, 2, 3]` |
| `split()` | Разбить строку на список по разделителю | `'1 2'.split()` → `['1', '2']` |
| `join(iterable)` | Собрать список строк в одну строку | `','.join(['a', 'b'])` → `'a,b'` |
